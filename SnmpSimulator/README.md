# SNMP Simulator

Contains a `.exe` and a Linux equivalent that provides a command to simulate X SNMP devices.

Repository: [RifautAlexis/snmp-simulator](https://github.com/RifautAlexis/snmp-simulator)

## Windows Command (Used Arguments)

```powershell
.\SnmpSimulator.exe startDevices .\config-devices\devices.json .\config-devices 127.0.0.1 161
```
